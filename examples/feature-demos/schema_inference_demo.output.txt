Document Schema Inference
========================================================================

  Four PDFs -- contract, invoice, research paper, policy.
  Layer 1: KeywordClassifier  (always, no API cost)
  Layer 2: LLMSchemaExtractor (OPENAI_API_KEY detected -- field extraction enabled)

------------------------------------------------------------------------
Step 1 -- Build pipeline with two-layer schema inference
------------------------------------------------------------------------

  pipeline = DocumentPipeline(
      classifier=KeywordClassifier(),
      schema_extractor=LLMSchemaExtractor(),  # one API call per document
      ...,
  )

------------------------------------------------------------------------

Step 7 -- DOCUMENT.FIND — filter documents by type
------------------------------------------------------------------------

  pipeline.find_schemas() queries across all ingested documents.
  Filter by document_type to narrow instantly — no re-read needed.

  find_schemas({'document_type': 'contract'})  ->  1 match(es)  ['sample_contract.pdf']
  find_schemas({'document_type': 'invoice'})  ->  1 match(es)  ['sample_invoice.pdf']
  find_schemas({'document_type': 'research_paper'})  ->  1 match(es)  ['sample_research.pdf']
  find_schemas({'document_type': 'policy'})  ->  1 match(es)  ['sample_policy.pdf']

------------------------------------------------------------------------
Step 8 -- DOCUMENT.FIND — filter by extracted field values
------------------------------------------------------------------------

  Filter on any field extracted by LLMSchemaExtractor:

  find_schemas({'fields.governing_law': {'contains': 'Delaware'}}):
    -> contract            governing_law='State of Delaware'

  find_schemas({'fields.total_due': {'gt': 30000}}):
    -> invoice             total_due='$35,154'

  find_schemas({'document_type': 'contract', 'confidence': {'gte': 0.7}}):
    -> contract            confidence=0.7778

------------------------------------------------------------------------
Step 9 -- Two-step query: DOCUMENT.FIND then DOCUMENT.SEARCH
------------------------------------------------------------------------

  The power pattern: structured filter → targeted text retrieval.
  Step 1: find matching documents by field value (deterministic).
  Step 2: retrieve specific text only within those documents.

  Step 1 — find contract documents:
    find_schemas({'document_type': 'contract'})  ->  1 document(s)
    document_id=doc_50407085c00a7db3  governing_law='State of Delaware'

  Step 2 — search for termination clause within contracts only:

========================================================================
Summary
========================================================================

  Two-layer schema inference + structured query:

    Layer 1 -- type detection (no API cost, no extra deps):
      classifier=KeywordClassifier()
      -> chunk['document_type']  and  schema['confidence']

    Layer 2 -- field extraction (one API call per document):
      schema_extractor=LLMSchemaExtractor()  # needs OPENAI_API_KEY
      -> schema['fields']  e.g. parties, effective_date, total_due, ...

    DOCUMENT.FIND -- query across all ingested documents:
      pipeline.find_schemas({'document_type': 'contract'})
      pipeline.find_schemas({'fields.governing_law': {'contains': 'Delaware'}})
      pipeline.find_schemas({'fields.total_due': {'gt': 30000}})

    Two-step pattern (structured filter + targeted text retrieval):
      docs    = pipeline.find_schemas({'document_type': 'contract'})
      doc_ids = [d['document_id'] for d in docs]
      chunks  = pipeline.search(query, filters={'document_id': doc_ids[0]})

  Supported document types (KeywordClassifier):
    * contract
    * invoice
    * policy
    * research_paper
    * financial_report
    * unknown
