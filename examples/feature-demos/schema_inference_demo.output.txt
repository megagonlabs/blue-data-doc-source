
========================================================================
Document Schema Inference
========================================================================

  Four PDFs -- contract, invoice, research paper, policy.
  Layer 1: KeywordClassifier  (always, no API cost)
  Layer 2: LLMSchemaExtractor (no OPENAI_API_KEY -- field extraction skipped)
           Set OPENAI_API_KEY to enable typed field extraction.

------------------------------------------------------------------------
Step 1 -- Build pipeline with two-layer schema inference
------------------------------------------------------------------------

  pipeline = DocumentPipeline(
      classifier=KeywordClassifier(),
      # schema_extractor not set -- add LLMSchemaExtractor() with OPENAI_API_KEY
      ...,
  )

------------------------------------------------------------------------

------------------------------------------------------------------------

========================================================================
Summary
========================================================================

  Two-layer schema inference:

    Layer 1 -- type detection (no API cost, no extra deps):
      classifier=KeywordClassifier()
      -> chunk['document_type']  and  schema['confidence']

    Layer 2 -- field extraction (one API call per document):
      schema_extractor=LLMSchemaExtractor()  # needs OPENAI_API_KEY
      -> schema['fields']  e.g. parties, effective_date, total_due, ...

  Ingest any PDF:
    records = pipeline.ingest('contract.pdf')  # page-by-page parsing
    records[0]['document_type']  # -> 'contract'
    records[0]['page_start']     # -> 1  (page number from PDF)

  Schema retrieval without re-reading:
    doc_id = records[0]['document_id']
    schema = pipeline.get_schema(doc_id)
    # {'document_type': 'contract', 'confidence': 0.83, 'fields': {...}}

  Supported document types (KeywordClassifier):
    * contract
    * invoice
    * policy
    * research_paper
    * financial_report
    * unknown

  To enable LLM field extraction:
    OPENAI_API_KEY=sk-... python3 examples/feature-demos/schema_inference_demo.py
