The manual two-step — verbose but equivalent
------------------------------------------------------------------------

  Without DOCUMENT.FIND_THEN_SEARCH the caller writes a loop:

    matched = pipeline.find_records({'document_type': 'contract'})
    seen, all_results = set(), []
    for doc in matched:
        chunks = pipeline.search(query, filters={'document_id': doc['document_id']})
        for chunk in chunks:
            if chunk['chunk_id'] not in seen:
                seen.add(chunk['chunk_id'])
                all_results.append(chunk)
    all_results.sort(key=lambda c: c.get('score') or 0, reverse=True)
    return all_results[:k]

DOCUMENT.FIND_THEN_SEARCH — same result, one call
------------------------------------------------------------------------

  source.execute_query({
      'op': 'DOCUMENT.FIND_THEN_SEARCH',
      'find_filter': {'document_type': 'contract'},
      'query': 'termination notice period',
      'k': 5,
      'mode': 'bm25',
  })

========================================================================
Summary
========================================================================

  DOCUMENT.FIND_THEN_SEARCH replaces:

    matched = pipeline.find_records(find_filter)
    results = []
    for doc in matched:
        results += pipeline.search(query, filters={'document_id': doc['document_id']})
    results = sorted(set(results), key=score)[:k]

  With:

    source.execute_query({
        'op': 'DOCUMENT.FIND_THEN_SEARCH',
        'find_filter': {'document_type': 'contract'},
        'query': 'termination notice period',
        'k': 5,
    })

  Key properties:
    find_filter  — same filter dict as DOCUMENT.FIND (type, field values)
    query        — text searched within matched documents only
    k            — cap applied after merge across all matched documents
    mode         — 'vector' (default), 'bm25', 'hybrid', or 'rerank'
    collection   — vector store collection to search in

  Zero matches on find_filter returns [] immediately — no search runs.

  Enable field-level find_filter:
    OPENAI_API_KEY=sk-... python3 examples/feature-demos/find_then_search_demo.py
