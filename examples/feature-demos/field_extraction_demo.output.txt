========================================================================
Summary
========================================================================

  Two-layer document classification and field extraction + structured query:

    Layer 1 -- type detection (no API cost, no extra deps):
      classifier=KeywordClassifier()
      -> chunk['document_type']  and  schema['confidence']

    Layer 2 -- field extraction (one API call per document):
      field_extractor=LLMFieldExtractor()  # needs OPENAI_API_KEY
      -> schema['fields']  e.g. parties, effective_date, total_due, ...

    DOCUMENT.FIND -- query across all ingested documents:
      pipeline.find_records({'document_type': 'contract'})
      pipeline.find_records({'fields.governing_law': {'contains': 'Delaware'}})
      pipeline.find_records({'fields.total_due': {'gt': 30000}})

    Two-step pattern (structured filter + targeted text retrieval):
      docs    = pipeline.find_records({'document_type': 'contract'})
      doc_ids = [d['document_id'] for d in docs]
      chunks  = pipeline.search(query, filters={'document_id': doc_ids[0]})

  Supported document types (KeywordClassifier):
    * contract
    * invoice
    * policy
    * research_paper
    * financial_report
    * unknown

  To enable LLM field extraction and field-level filtering:
    OPENAI_API_KEY=sk-... python3 examples/feature-demos/schema_inference_demo.py
