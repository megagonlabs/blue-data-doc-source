Integration
====================================================================

  BasicEnricher runs automatically inside DocumentPipeline:

    pipeline = DocumentPipeline(enricher=BasicEnricher())
    records  = pipeline.ingest('doc.txt')
    chunk    = records[0]
    chunk['entities']       # → list of {label, text} dicts
    chunk['semantic_hints'] # → {word_count, keywords, …}

  Swap in a custom Enricher subclass for ML-powered entity recognition:
    pipeline = DocumentPipeline(enricher=SpacyEnricher())
