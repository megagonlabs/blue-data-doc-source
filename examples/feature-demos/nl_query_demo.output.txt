
====================================================================
NLQueryParser Demo
====================================================================

  Backend: regex parse_fn (no API key)

  NLQueryParser maps natural-language strings to structured op dicts.
  Default backend: OpenAI gpt-4o-mini.
  Custom parse_fn: inject any callable (text: str) -> dict.

====================================================================
How to wire it up
====================================================================

  # Default: uses OpenAI gpt-4o-mini
  parser = NLQueryParser(api_key='sk-...')

  # Custom: inject any callable
  parser = NLQueryParser(parse_fn=lambda t: {'op': 'DOCUMENT.SEARCH', 'query': t})

  source = DocumentDataSource(
      name='docs',
      nl_parser=parser,   # ← inject at construction time
      …,
  )
  results = source.execute_query_nl('find the termination clause')

  Without nl_parser=, execute_query_nl raises ValueError.
