======================================================================
  Summary — when graph traversal outperforms keyword/vector search
======================================================================

  Question                                 Search                           Graph
----------------------------------------------------------------------
  Exact entity lookup across corpus        BM25/KNN — k-capped, may miss docs Node lookup + MENTIONS hop — exact, no cap
  Docs mentioning entity A AND B           Two queries + intersect (k-limited) Neighbour intersection — complete
  Reading-order context expansion          Re-query — cross-doc noise       NEXT/PREV — same doc, in order

  Graph traversal complements — not replaces — vector search:

    Vector/BM25:  'find chunks about cost-sharing arrangements'
    Graph:        'find every chunk naming Acme Corp'
    Graph:        'which docs mention both Sarah Chen and Acme Corp?'
    Graph:        'show me what comes before and after this finding'

  Combined:  DOCUMENT.FIND_THEN_SEARCH filters documents by entity
  or extracted field first, then runs vector search only within
  the matched documents — best of both in a single call.
