========================================================================
Summary
========================================================================

  One collection, many documents:
    pipeline.ingest_text(text, file_name=...)  ← one call per document
    pipeline.ingest('file.pdf', collection=...) ← or directly from file

  Search spans the entire collection:
    pipeline.search('query', k=5)  ← returns top chunks across all docs

  Every result carries full provenance:
    result['file_name']     → which document
    result['section_title'] → which section
    result['page_start']    → which page (PDF/page-aware ingestion)
    result['document_id']   → stable content-addressed ID

  Each document is independently deletable:
    pipeline.delete(document_id=..., chunk_count=...)
    → removes that document's chunks; others are untouched

  Note: this demo uses DummyEmbeddingModel (SHA-256 hash vectors).
  For real semantic search across documents, use OpenAIEmbeddingModel.
  See examples/backends/openai_embeddings_demo.py
