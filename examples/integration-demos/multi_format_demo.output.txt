Multi-Format Ingestion Demo
====================================================================

  The same pipeline.ingest() call works for .txt, .pdf, and .docx.
  Format detection is automatic; the chunk schema is always ChunkRecord.

====================================================================
Result
====================================================================

  One pipeline, three formats:
    pipeline.ingest('doc.txt')   → TextParser  → flat chunks, page=None
    pipeline.ingest('doc.pdf')   → PDFParser   → page-scoped, page=1,2,…
    pipeline.ingest('doc.docx')  → DocxParser  → page-scoped, page=1,2,…

  Bypass methods for programmatic input:
    pipeline.ingest_text(text, ...)       → flat, like .txt
    pipeline.ingest_pages(pages, ...)     → page-scoped, like .pdf
