Result
====================================================================

  Add   : pipeline.ingest(path)  or  DOCUMENT.INGEST
  Remove: DOCUMENT.DELETE with document_id + chunk_count
  Update: DELETE old doc_id  →  INGEST new file

  Content-addressing means:
    • Unchanged files are safely re-ingested (upsert, no growth)
    • Changed files get a new document_id — old chunks need explicit DELETE
    • Track document_id at ingest time so you can DELETE later
