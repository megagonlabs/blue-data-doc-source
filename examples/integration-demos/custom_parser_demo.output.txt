--------------------------------------------------------------------
Parser ABC interface
--------------------------------------------------------------------

  from blue_doc_source import Parser

  class MyParser(Parser):
      def parse(self, path: str) -> list[dict]:
          # Return one dict per page:
          # {"page_num": int,   ← optional; sets page_start/page_end
          #  "text": str}        ← required

  pipeline = DocumentPipeline(parser=MyParser(), ...)
  records  = pipeline.ingest("doc.pdf")

  Alternative — bypass the parser layer entirely:
  records = pipeline.ingest_pages(pages, file_name="doc.pdf")
  records = pipeline.ingest_text(text,  file_name="doc.txt")

====================================================================
Result
====================================================================

  Mode A (Parser ABC): cleanest when you always use the same extractor.
    pipeline.ingest(path) works as normal; your parser is called internally.

  Mode B (bypass): best when extraction already happened elsewhere, or
    when you want to feed content that has no file on disk.
