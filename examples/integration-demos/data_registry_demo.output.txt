====================================================================
Result
====================================================================

  DocumentDataSource participates in DataRegistry like any other source:
  - register_source  → source is addressable by name
  - sync_source      → registry learns ChunkRecord schema automatically
  - search_records   → registry metadata is searchable
  - execute_query    → DOCUMENT.* ops run via the registry interface
  - execute_query_nl → NL dispatch when NLQueryParser is wired up

  Agents built on DataRegistry can retrieve document evidence and
  cross-reference it with SQL, graph, or JSON sources — no per-
  integration glue code required.
